以團隊 repo 的東京手機版 Demo 為基礎重建，保留原本品牌、行程資料和圖片；新程式全部放在 `frontend/`。不依賴後端，AI、付款及社群發文均為可操作的模擬。

## 航照切換與重遊完成總結（2026-10-04）

**2026-10-07 更新，優先於下方舊版等待秒數：** 進入重遊或切換旅程時，先準備所選旅程的全部本機航照階層、原照、貼紙拆件與三種互動收藏，以及交通走廊的低解析底圖、目的地／沿途地形。`revisit-preload.ts` 去重後最多六個下載並行，完整讀完 response body 才記進度；預載和 MapLibre 都使用同一 URL 與 `force-cache`，不把所有圖片同時解碼留在記憶體。準備完成才能開始；失敗可重試或先看照片回憶，切換旅程／離開會取消舊下載與進度事件。

下載完成不等於 GPU 已渲染。出發、俯瞰、下降中段與近景都等當前關鍵來源完成並實際 render 兩幀，原有短逾時不再直接放行；慢載入會停在目前視角，顯示可操作準備提示，使用者可先看該站照片。沿途地形尚未就緒时，不累加交通動畫時間。保留連續鏡頭，沒有再加不透明照片遮罩。預載範圍是目前行程的素材與預計走廊；使用者拖到其他位置仍可能載入新圖磚，不宣稱整個世界或所有精細實景都已預渲染。

照片使用非模態底部／側邊面板，地圖不再被原生 `showModal()` 鎖住。拖曳、縮放、旋轉會停止引導、收起照片並保留當前站與收藏進度，顯示「回到這一站」；取消動畫時不呼叫會重設手勢的 `map.stop()`。路線與總結仍保留模態焦點管理；照片 Escape 可關閉，收藏內的 Escape 優先返回照片。

本輪驗證：53 項測試、Nuxt 型別與 24 路徑建置；390px 開著照片拖地圖、關西七站自動完成、320px 手動下一站與無橫溢、桌面拖曳／Escape／減少動態；單張預載圖磚逾時阻止開始並可重試；下降中段攔住圖磚會等待、未提前開照片，解除後可繼續。證據 `outputs/revisit-preload-2026-10-07/`（工作區）。本機 8780，未提交／推送。

入口 `/atlas?view=cities&journey=kansai`。移動階段保留低解析 EOX 連續底圖；到站停穩後，衛星／日本航照各自等目前視野圖磚完成才整層淡入（650ms），不以逐片淡入露出白色素模。目的地準備最多等 1.4 秒，接著照常開照片；慢網路時保留連續底圖，細節準備好後仍可淡入。跳過移動／減少動態不等這段時間。此機制改善視覺拼接，不保證外部圖磚即時到齊，亦未增加精細實景模型。日本航照只在日本站點載入，保持原始來源署名。

MapLibre 保留縮放途中未完成的粗階圖磚，渲染倍率上限 2；車輛／鏡頭維持逐幀移動，示意交通線 GeoJSON 約每 80ms 更新，減少 worker 與主執行緒資料更新負擔。地圖樣式與兩個引擎並行載入。`revisit-tiles.ts` 的就緒等待沿用每段可取消的 run，跳站、拖動或離開會移除舊監聽與 deadline。

最後一站倒數歸零或按「完成這趟重遊」開 `RevisitSummary`，以照片接觸表收尾，显示回顧景點、打開收藏、已有作品與收藏縮圖。照片確實載入才列入本次，跳站不補算；重複打開同件收藏去重。示範互動與實際所有權分開，重遊不新增作品。資料在本次 Nuxt 頁面記憶體中，重新整理依既有錄影規則復原；不是帳號的永久統計。

總結可返回同一站與進度、重新從第一站走（重設本次統計），或回到廣場。手機採底部可捲動面板、底部操作固定，桌面居中；原有收藏流程不變。年度與去年同用收尾，未出發東京不列入。

`/esim?trip=tokyo` 主頁保留 AI 流量顧問、目的地方案卡、同行福利與兩個加值入口。固定底部選購；方案比較、每日估算、組隊、回饋、結帳與安裝透過面板展開，不把功能全鋪在主頁。
