## 主畫面只做一件事：創作一件旅行作品

預設為本趟照片相簿。點選照片後，桌面採作品／操作雙欄；手機採短版單欄。原照、六種形式與「這張照片的作品」維持在同一工作區；六種範例說明、上傳、交換、收藏、來源資訊與互動由按鈕開啟。切換形式沿用同一張原照，不會跳到另一個景點。

關西含兩张 USJ 照片、京都、奈良；富士山另屬二月旅程；東京尚未出發，使用空相簿。所有本次作品、交換來源及旅伴跟隨行程；回憶地圖才跨行程查看。舊收藏按來源照片遷移，舊儲存鍵保留。

| 功能 | 目前可操作 | 狀態與規則 |
| --- | --- | --- |
| 六種風格 | 貼紙卡、專業攝影、旅行票根、琺瑯徽章、場景積木、景點限定旅伴 | 每張照片皆可選；有專屬圖時用預製成品，其餘以同張原照做清楚標示的版型合成 |
| 生成與收藏 | 生成中狀態、完成後自動收藏、手動收藏、放大、下載 | 本機保存收藏；不呼叫 AI |
| 上傳 UI | 選檔、拖放、預覽、換照片、範例入口 | JPG/PNG/WebP，20MB 上限；只在記憶體預覽，不上傳、不保存私人照片 |
| 交換 | 選朋友、選對方任一格式、留話、預覽、送出 | 交換收藏副本；双方保留原作 |
| 收件與紀錄 | 收到邀請、接受／婉拒、撤回已送邀請、模擬朋友接受 | 待接受／完成／婉拒／撤回，完成後不可再處理 |
| 同行紀念 | 同行朋友標記、共同旅程名稱、同行收藏提示 | 一般朋友不顯示同行標記 |
| 作品來源 | 原作者、地點、創作日、交換對象、時間、留言／回覆 | 收到後可從「我的收藏 → 作品 → 查看來源」追溯 |
| Threads | 編輯文字、圖片移除／恢復、500 字限制、草稿、回覆對象、話題提示、貼文預覽 | 不真的登入或發文；可複製文字、下載圖片 |

## 六種作品與互動深度

| 格式 | 這版互動 | 後續可延伸 |
| --- | --- | --- |
| 貼紙卡 | 六枚透明貼紙拖曳到手帖、揭角／抬起陰影、放手回彈；可重排／重置，亦有點按替代 | 地圖擺放、共同貼冊與跨次保存排列 |
| 專業攝影 | 原照／調色滑桿、按住原照、相紙傾斜 | 真正攝影生成、分層景深視差 |
| 旅行票根 | 抽出票套、正反翻面、壓印紀念章 | 連結當天紀錄與收藏印章 |
| 琺瑯徽章 | 獨立透明徽章、指尖傾斜與遮罩高光、同輪廓背面、別上收藏板 | 可保存的個人徽章板 |
| 場景積木 | 五組獨立 Three.js 零件：富士山、咖啡店、杉樹、路燈、雲霧；拖曳近目標吸附，或逐件點按放入；可重拼、旋轉、切換光線 | 更精緻的 3D 美術與交換零件 |
| 景點限定旅伴 | 獨立透明毛氈角色，走近方塊、起跳、方塊回彈、星星收入與歸位的 GSAP 序列 | 關節骨架、更多景點服裝與動作 |

交換完成後，送出邀請及收到邀請兩個入口皆可打開收藏封套，作品滑出後展開朋友留言與同行標記。

互動由 `CreationPlayground` 按格式分派到小元件；`useCreationMotion` 管理 GSAP context、生命週期與減少動態偏好。原本 `CreationScene.client.vue` 保留，新拼裝體驗使用 `CreationBuildScene.client.vue`。

專業攝影仍是來源照片加 CSS 調色，沒有 AI 生成或景深分層；3D 場景是手工幾何而非由圖片自動建模；吉祥物是獨立精靈圖動畫，沒有手腳骨架。貼紙、徽章和角色是真實帶 alpha 的新生成素材。手帖排列、蓋章、拼裝和星星數目前只在互動視窗內保留，關閉後重新開始；收藏及交換來源仍採既有本機保存。

## 建議的 Demo 操作

1. 在我的行程選關西 → AI 創作 → 樹影下的鳥居 → 製作琺瑯徽章 → 本次作品。
2. 點「與朋友交換」，選 James（同行）、挑選對方作品、留話，預覽後送出。
3. 點「模擬 James 接受」並打開朋友的封套；從本次作品查看作者、同行標記與留言。
4. 再選阿霖，確認一般朋友不顯示同行 UI；邀請送出後也可從交換紀錄撤回。
5. 分享到 Threads，展開話題提示、存草稿、再開啟預覽。此流程不對外發文。
6. 切換富士山旅程，只有富士山照片與作品；點照片 → 場景積木 → 拼回這片風景。關西的作品仍完整保留。
7. 回憶地圖 → 依期間 → 開始回顧：二月富士山串接四月關西，不包含未出發東京。同站多形式可從收藏視窗切換，不拆成多次造訪。
8. 每站先看原照片，1.4 秒後出現收藏提示；點選即暫停。已保存的 USJ 場景能進入原有 3D 互動，已完成的 James 交換才顯示同行事件。按繼續恢復，上一段／下一段可隨時控制。

## 照片探索・拾光（2026-10-02）

同日精修：首頁改為「那天的風景，再看一眼」，物件說明以照片可見內容及選填提問為主，不替使用者編造心情。新增 `MemoryMotionIcon.vue` 自繪 SVG，修正返回箭頭的字型基線偏移；提示星光、收藏書頁、書籤和勾選採短動態。原生 dialog 初始焦點移到返回鍵，SVG 探索點取消矩形焦點外框、保留輪廓提示。GSAP timeline 控制文字進場，quickTo 控制桌面照片與文字的輕微反向視差；觸控裝置不啟用滑鼠視差，減少動態設定停止此效果。沿用既有素材與 GSAP，未添加第三方圖示動畫框架。

參考：[Lucide Animated](https://github.com/pqoqubbw/icons) 的局部圖示互動、[GSAP quickTo](https://gsap.com/docs/v3/GSAP/gsap.quickTo()/) 的高頻指標動畫用法。圖示路徑與此頁動態在專案內實作，沒有複製其整站或安裝 React 依賴。

本次精修通過型別檢查及建置，實測返回箭頭中心誤差小於 1px、桌面視差、三件收藏、留言、焦點返回與 reduced-motion；320／390／1440px 已視覺檢查，無 pageerror。產物在工作區 `outputs/photo-polish-2026-10-02/`。

貼紙卡新增「走進照片，拾起回憶」入口，開啟獨立滿版體驗；原本「揭起貼紙」的手帖保留。

1. 富士山藍調照片提供山、咖啡店、路燈三個探索點；可拖曳、縮放或開啟提示。
2. 點選物件時，照片局部從原位置浮起，再轉換成預製貼紙。主動畫約 580ms，細節面板稍後進場。
3. 可留一句回憶，按收藏後貼紙沿兩段弧線收入右上收藏冊，約 500ms；重複查看不增加數量。
4. 收藏冊保留三枚貼紙的狀態、短句與回到照片的入口，也可打開既有自由拼貼手帖。

桌面採右側回憶面板，手機採底部面板。操作具有鍵盤入口、Esc 分層返回與焦點復原；減少動態設定會直接呈現結果。留言區預設收起。照片探索的收藏與短句使用 `chictrip-photo-exploration-v1` 本機儲存，與既有六格式作品收藏分開；不會自動把它們貼到手帖或地圖。
