# 去趣 3D 記憶星圖

入口：回憶廣場 `/atlas` 的「3D 記憶星圖」，或直接開 `/memory-graph`。

此版本採用去趣黃藍吉祥物的 3D 中心造型、漸層弧線、關聯光點、平順節點放大與八類回憶分群。無表情符號及造型選擇卡。

## 展示流程

1. 從回憶廣場開啟星圖，拖曳旋轉或使用方向鍵，滾輪、雙指及加減按鈕可縮放。
2. 點美食或玩樂分類，查看同類回憶與關聯。
3. 點節點或標籤，閱讀筆記及反向連結；滑過標籤可預覽相關路徑。
4. 新增／編輯筆記，輸入 `[[筆記名稱]]` 建立連結；改分類會更新顏色與分群。
5. 使用暫停流光、自動旋轉及置中控制展示。

## 實作範圍

- Nuxt / Vue、既有本機 Three.js；不需新的網路套件。
- 初始 16 段虛構旅行回憶。筆記儲存於目前瀏覽器 localStorage，尚未串接帳號、雲端同步或 AI 自動記憶。
- 沿用原 `chictrip-memory-graph-v1` 儲存資料；初次分類升級保留已有文字並補入缺少的示範筆記。
- 支援 WebGL 失敗提示、鍵盤控制、系統減少動態偏好，離頁釋放 WebGL 資源。
- 吉祥物為依專案既有參考圖以幾何建構的示範模型。
