# 經典行程景點照片

2026-10-09 補齊 19 條經典路線的 182 個不同地點。各站使用景點本身的網路實景照片，去程與返程的同一機場共用圖片。照片以 WebP 隨網站提供，不依賴訪客連線到第三方圖片網站。

`credits.json` 逐張記錄景點、原始檔名、作者、來源頁、下載網址、授權資訊、取得日期與尺寸轉換。主要來源為 Wikimedia Commons；未收錄的景點使用政府文化、官方觀光網站的參考照片。官方照片保留其原權利人資訊，不宣稱為 Creative Commons 素材。各照片授權以來源頁為準。

前端對照資料在 `app/data/stop-photos.json`。新增經典行程景點時，須同步準備可讀取的圖片與來源；`classic-routes.ts` 不再以路線 SVG 補空白，也不覆寫照片署名。`tests/stop-photos.test.ts` 檢查所有行程及雨天替代站的圖片檔格式，並核對經典路線的來源資料。
