# chicTrip eSIM 提案展示

主站已改為 Scott 的 chicTrip demo（原 `lagacy/`）。

線上入口：https://wiwincolab.github.io/demo-repository/

| 路徑 | 內容 |
|---|---|
| `/` | 主站（旅伴組隊省 / Group Trip Deal） |
| `/chictrip-v4/` | 團隊提案原型 v4 備份 |
