## 九宮格編輯（2026-10-09）

`public/demos/travel-town/town-editor.js` 提供整個街區拖移交換、地面吸附提示、點選兩格交換、上一步、原始排列。編輯時關閉鏡頭控制，完成後恢復。支援 Pointer Events、拖出範圍回原位、Escape／失焦／取消觸控時還原。固定格位、不旋轉街區；這不是自由造鎮或建築拆解。

原始內嵌 GLB 與 Three.js 引擎保留，執行 HTML 僅載入獨立 editor 並在場景啟動末端提供必要的建構子、場景控制器與 invalidate。更新原始 HTML 時需要重新接上這兩個掛鉤。移動後更新街區位置、景點聚焦範圍、光源與陰影。

單獨開啟頁面使用 localStorage `chictrip:town-layout:v1`；App 內仍維持不含 allow-same-origin 的 sandbox，以 `town.vue` 的來源視窗檢查和完整 0–8 排列驗證處理保存訊息。保存失敗會提示僅在本次保留。上一步紀錄只保留本次操作，最多 30 步。

## 天文天空（2026-10-11）

天空預設跟隨現在時間，每 15 秒更新。選取景點會切換觀測座標；第一次全景使用大阪超級任天堂世界，之後全景沿用目前顯示的觀測地點。時間預覽保存同一個 UTC 瞬間，切換觀測地點重新計算位置。日本與韓國均使用各自的 IANA 時區，不依賴瀏覽器所在時區。滑桿表示 00:00–23:59，日期與日出／正午／日落／月出／月落快捷會停止即時更新，按「現在」恢復。當天無升落事件時停用對應按鈕，不能用下一天的事件冒充。

- `sky-core.js`：九個觀測點、當地時間轉換、天文位置、角直徑、月面照亮比例和升落事件。座標取自專案 `public/poi/regions/` 的 OpenStreetMap 快照，保留各筆來源連結；富士山／河口湖街區以大石公園為觀測點。街區重新排列不改變觀測座標。
- `town-astronomy.js`：控制介面、即時時鐘、天空與日月光源、月相 shader 和觀看天空。天文計算和原模型的載入不需要外部服務。
- `vendor/astronomy.browser.min.js`：固定版本 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/tree/v2.1.19)，MIT 授權見同目錄 `astronomy.LICENSE`。SHA-256：`f41139a87941ea017ab902b954c9389fa27ea72083d7fab4971756d7769d14e6`。

位置用 Observer → Equator（topocentric、of-date、aberration）→ Horizon（標準大氣折射）計算。世界方位固定為北 -Z、東 +X、天頂 +Y；鏡頭旋轉不改變地理方位。「看太陽／看月亮」視角以真實角半徑渲染盤面，錨定鏡頭以避免近距離球體的錯誤視差，shader 依地平線裁切；全景則用放大的日月位置標記，方便看清移動。月面明暗使用同一座標系中的 Moon→Sun 向量計算，方向和亮面比例隨日期、時間、地點與觀看方向更新。太陽／月亮方向光使用對應的方位，時間和地點變更都重新計算陰影。

範圍：海平面觀測基準、平坦地平線、標準折射；未輸入地形高程、山地遮擋、即時氣象或雲量。天空顏色、照明強度、曝光、既有星點和月面紋理仍是可視化近似；未模擬月球表面天平動或日月食的遮蔽效果。這是天文位置與月相的真實化，不能宣稱整張畫面等同現場照片。

驗證：`tests/fixtures/town-jpl-horizons.json` 保留 24 筆 NASA/JPL Horizons DE441 海平面東京觀測資料，含日間／夜間及不同月相。`tests/town-astronomy.test.ts` 核對無折射方位／高度（允差 0.005°）、角直徑（2 角秒）、月面照亮比例（0.0001），另檢查九個觀測點的升落、季節差異、時區跨日與日間月亮。完整前端測試及型別檢查已通過；瀏覽器回歸檢查涵蓋九景切換、光源方向、月相 shader、仰望／全景、編輯／上一步、手機及橫向排版。

`index.html` 只替換場景自己的天文函式、時間控制和幾個適配掛鉤，內嵌模型及 Three.js 引擎位元組未改變。離線分發需保留本資料夾的 HTML、CSS、適配器及 vendor 檔案。

### 日夜動態（2026-10-12）

全景以太陽球體／月亮盤面作為天空位置標記，方位與高度仍來自真實觀測地點、日期和時間。球體顯示半徑 2.4、距離 30 是示意比例，方便在小鎮上看清移動，不代表太陽或月亮的物理尺寸。個別天空視角維持實際角直徑。太陽使用光球層 shader；月亮明暗比例沿用實際月相，避免示意距離造成錯誤視差。

依使用者的顯示偏好，太陽盤面高於地平線時只呈現太陽，其餘時間只呈現已升起的月亮。這是日夜顯示篩選；真實月亮也可能白天出現，天文資料未因此改動。月亮未升起、已落下或接近新月時不捏造滿月。太陽方向光、月光和街區陰影仍使用真實位置。

「播放日夜」以每秒 30 分鐘推進選取景點的當地時間，到當日 23:59 停下，保留日期供核對；不把下一天的月球軌跡接回起點。介面標示「日夜播放」，可暫停、拖動滑桿、切換日期，或按「現在」恢復即時時鐘。切換景點和編輯小鎮會暫停，頁面隱藏沿用原排程暫停，不補播離開期間。沒有軌跡線、地平線圈、倍率特寫或升落浮標。

光球粒紋、邊緣變暗和顯示柔光屬於視覺近似，概念來源是 [NASA 太陽分層](https://science.nasa.gov/blogs/the-sun-spot/2023/09/26/layers-of-the-sun/)，沒有使用即時太陽黑子或耀斑資料。

## 去趣散步旅伴（2026-10-11）

`town-walkers.js` 參考現有 `assets/memory/references/chictrip-mascot.png` 和 `assets/memory/motion/companion.png`，以原生幾何製作六位小型 3D 吉祥物：黃色圓角三角臉、藍色身體、大眼睛、吊帶褲、小帽子與布鞋。這是該角色的簡化立體版本，沒有使用站立圖片滑行。手臂與雙腿按步行距離交替擺動，身體有輕微起伏，轉身沿弧線連續進行。三組帽子／服裝配色共用幾何與材質。

`walker-paths.js` 沿九格共用的 `PATH_E`／`PATH_W` 步道（局部 Z=2、寬 1.42m、表面 Y≈0.15）提供三條來回環線。兩條行走方向略微錯開，盡頭轉彎與角色輪廓均留在步道和街區內。街區交換保持共同接點，因此排列不改變路線。角色是場景的獨立群組，沒有混入編輯器的九個街區子節點。

散步共用原渲染器、日月／環境光及 requestAnimationFrame 排程；離屏或頁面隱藏時沿用既有暫停機制，不追補離開期間的步數。編輯時收起角色並暫停，完成後在原位置繼續；仰望天空時停止散步更新。介面提供開始／暫停，裝置的 `prefers-reduced-motion` 預設停下，可由使用者手動開始。角色使用近似接地陰影，不重新渲染整座小鎮的建築陰影圖；離開時清理監聽器、觀察器、幾何及材質。

驗證：路線測試檢查足跡範圍、等速、轉彎和環線接點；瀏覽器檢查六個角色的位移／擺腿、真正模型步道高度、暫停、編輯／上一步、減少動態，以及手機／橫向排版。原內嵌 GLB 與 Three.js 引擎未改動。
