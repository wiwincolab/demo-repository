# 去趣行程偏好圖 Demo

入口：上方吉祥物 → 記憶偏好 `/wardrobe?view=preferences`。舊 `/memory-graph` 連結導向此處。行程規劃只顯示精簡摘要及本次套用開關。

## 展示流程

1. 選用咖啡與甜點、自然景觀、老街與文化、樂園與體驗或購物與逛街等偏好關鍵字。
2. 點選按鈕開啟獨立 3D 偏好圖視窗（預設收起），以去趣吉祥物為中心，點選節點查看與調整推薦依據。支援旋轉、縮放、曲線與流光，沒有表情符號或造型選擇器。
3. 圈選主要旅遊範圍，再補充可用時間、雨天或圈外交通等本次條件。
4. 產生推薦，每個景點顯示採用的偏好。明確排除、時間與範圍限制優先；可關閉整組偏好。
5. 確認後才儲存行程；調整偏好會要求重新產生推薦。

## 實作範圍

- Nuxt / Vue 與既有本機 Three.js。
- 關鍵字是可自行選用的示範資料，不會假裝已從帳號或歷史自動分析；目前按景點名稱與規則排序，尚未串接 AI。
- 偏好保存在目前瀏覽器 `chictrip-planner-keywords-v1`，行程快照記錄當次選用關鍵字。
- 原有回憶筆記的 localStorage 資料不刪除；回憶廣場不再放此功能入口。
- WebGL 失敗時仍可透過關鍵字按鈕規劃，支援減少動態與資源清理。
